# LiciTot — Brand book

> **Totul se licitează.** Simple, trustworthy, friendly.
> Live version with rendered components and computed contrast: **`/brand`**.

## Concept

A price tag whose silhouette is an upward arrow, with an arrow inside it: _the price goes up with
every bid_. White and baby blue keep the platform light and calm; a deeper blue carries everything
that must be read or clicked.

## Colors

Source of truth: `src/lib/brand/tokens.ts` (mirrored in `src/app/globals.css`). `pnpm test` fails if
the two drift or if any pair below drops under WCAG AA.

| Token              | Light     | Dark      | Use                                                   |
| ------------------ | --------- | --------- | ----------------------------------------------------- |
| `background`       | `#FFFFFF` | `#0B1320` | Page background                                       |
| `foreground`       | `#0F1B2D` | `#E6EEF7` | Body text                                             |
| `sky` (baby blue)  | `#8EC9F5` | `#8EC9F5` | Surfaces, highlights, the logo tag. **Never text.**   |
| `sky-soft`         | `#E8F4FD` | `#13283F` | Section backgrounds, chips                            |
| `primary`          | `#1D6FC2` | `#8EC9F5` | Buttons, links, prices (in dark mode baby blue leads) |
| `primary-hover`    | `#1A66B3` | `#A9D6F8` | Button hover (solid, not opacity)                     |
| `muted-foreground` | `#52627A` | `#9DB0C7` | Secondary text                                        |
| `border`           | `#DCE5EF` | `#22324A` | Dividers, card borders                                |
| `input`            | `#7C8DA3` | `#5A6F8C` | Form control borders (≥3:1)                           |
| `success`          | `#157F3D` | `#4ADE80` | Won, paid, active                                     |
| `warning`          | `#A15C07` | `#FBBF24` | Ending soon, reserve not met, demo banner             |
| `destructive`      | `#C2281D` | `#F87171` | Errors, outbid, cancelled                             |

Each status color has a `-soft` background (`success-soft`, `warning-soft`, `destructive-soft`).

**Contrast notes**

- Baby blue `#8EC9F5` on white is **1.78:1**, so it's for decoration only.
- The suggested `#2276C9` passes at only 4.66:1, so we use **`#1D6FC2` (5.12:1)** for margin.
- White on `#1D6FC2` is 5.12:1, and navy on baby blue (dark-mode buttons) is 10.5:1.

## Logo

Files in `public/brand/` are generated by `pnpm icons` from `src/lib/brand/logo-geometry.ts`. In the
app, use `<Logo/>` and `<LogoMark/>` from `src/components/brand/logo.tsx`.

| File                  | Use                           |
| --------------------- | ----------------------------- |
| `logo.svg`            | Default, on light backgrounds |
| `logo-reversed.svg`   | On dark backgrounds           |
| `logo-mono.svg`       | Single color (print, stamps)  |
| `logo-mono-white.svg` | Single color on photos/dark   |
| `logo-mark.svg`       | Icon only (avatars, favicons) |
| `logo-mark-mono.svg`  | Icon only, single color       |

Favicon: `src/app/icon.svg` + `favicon.ico`. Apple icon: `apple-icon.png`. PWA icons:
`public/icons/` (192, 512, maskable 512). OG template: `src/lib/brand/og.tsx`, used by
`app/opengraph-image.tsx`.

**Rules**

- Keep clear space around the logo equal to twice the tag-hole diameter.
- Minimum size is 24 px for the mark and 96 px wide for the full logo.
- Use the mono version on photos or saturated backgrounds.
- Don't rotate, stretch, recolor, outline or add shadows to the logo.

## Spacing, radius, shadows

- **Spacing:** a 4 px grid. Prefer Tailwind steps 1, 2, 3, 4, 6, 8, 12, 16. Page gutters are `px-4` (mobile) and `md:px-6`. Max width is `max-w-7xl`.
- **Radius:** `--radius` is 12 px. Buttons and inputs use `rounded-lg`, cards use `rounded-xl`, and chips and search use `rounded-full`.
- **Shadows:** `shadow-card` (resting cards), `shadow-raised` (hover, hero), and `shadow-overlay` (menus, sheets). They are subtle and only separate layers.

## Components

- **Buttons:** minimum height is 40 px (`default`), with `sm` 36, `lg` 48 and icon buttons 40.
  - Variants: `default` (primary), `secondary` (sky-soft), `outline`, `ghost`, `destructive`, `link`.
  - There is one primary button per view. "Licitează" is always the primary action.
- **Inputs:** 40 px tall with an `input` border (3:1). Errors use `aria-invalid` plus a message in `text-destructive` linked by `aria-describedby`.
- **Cards:** `rounded-xl border bg-card shadow-card`, with a 4:3 image on top. The price is in `text-primary font-extrabold`.
- **Status badges** map auction states to variants:

  | State       | Romanian label    | Badge variant |
  | ----------- | ----------------- | ------------- |
  | active      | Activă            | `success`     |
  | ending soon | Se termină curând | `warning`     |
  | sold        | Vândută           | `sky`         |
  | unsold      | Nevândută         | `secondary`   |
  | cancelled   | Anulată           | `danger`      |
  | draft       | Ciornă            | `outline`     |

- **Focus:** a 2 px `ring`-colored outline on every interactive element. Never remove it.

## Tone of voice

We sound like a friend who knows the ropes: clear, warm and to the point. We always use **"tu"**.

| Așa da ✓                                             | Așa nu ✗                                                     |
| ---------------------------------------------------- | ------------------------------------------------------------ |
| Ai fost depășit! Mai licitezi?                       | Oferta dumneavoastră a fost depășită de un alt utilizator.   |
| Felicitări, ai câștigat! Plătește în 3 zile.         | Licitația s-a finalizat cu succes. Vă rugăm efectuați plata. |
| Vei primi aproximativ 950 RON după comisionul de 5%. | Se aplică un comision conform termenilor.                    |

- **Short sentences, verbs first:** "Licitează", "Pune pe licitație", "Plătește acum".
- **Be transparent about money.** Always show the fee and the final amount.
- **Errors say what happened and what to do next.** Don't blame the user.
- **Minimal emoji.** At most one, only in celebratory messages.
